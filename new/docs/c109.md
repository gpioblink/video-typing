# 通常の学習UIとクリップ起動

開発対象は `new/` のWXT / React / TypeScript製MV3拡張です。直下のReact 16 / Storybookは初期プロトタイプとして維持しています。

## 起動と検証

Node 24、pnpm 10.12.4を使用します。

```sh
cd new
pnpm install --frozen-lockfile
pnpm dev:web
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm build:web
pnpm exec playwright install chromium
pnpm test:e2e
# 外部サービスの実再生検証（通常CIとは分離）
pnpm test:youtube
```

Webデモ: https://gpioblink.com/video-typing/

おすすめは選ぶと用意済みの区間で即開始します。自分の動画と字幕を使う場合だけ、開始・終了秒または字幕の境界を選んで「開く」を押します。開始前に全画面 / ミニ画面を選べます。全画面は学習UIを含めてFullscreen APIで表示し、Escでミニ画面へ戻せます。開いた画面は拡張と同じ `OverlayApp` / `DraggablePanel` / `TypingPart/Window` / `Hint` / `ConfigPanel` / `SubtitlePanel` です。別のタイピングゲームは実装していません。未完了の問題は通常版と同じようにループし、選択区間の入力を完了すると再挑戦できます。

動画は区間準備完了後に自動再生します。IFrame APIのonReady直後に再生すると後続CUEDイベントが再生を打ち消すため、CUEDを確認してからplayVideoを呼びます。音声はミュートしません。ブラウザ側の制限で止まった場合は公式プレーヤーの再生ボタンを使用できます。独自のControlsウィンドウ・再生・聞き直しボタンは設けません。

初回は背景を暗くして対象をスポット表示します。①入力とシーンの自動リピート、②初めての誤入力で継続入力・スロー/対応動画の日本語音声ヒント、③初めての誤答単語完了で誤答理由、④理由記録と実際の辞書結果を確認して意味の表示、⑤説明終了と学習履歴・CSV/Anki出力の案内、という5段階です。4は次の入力または「確認しました」で進みます。誤入力しなければ2以降へ勝手に進まず、ゲームの完走を妨げません。案内は右上の小さい×やEscで閉じ、ヘッダーの「？」から再表示できます。

入力エンジンの挙動は維持し、初誤答単語完了を通知するoptional callbackだけを追加しています。古いフレームや別単語の辞書結果では段階を進めません。「知らなかった」の記録には既存の意味選択UIを使います。

初期配置はTypingが画面中央下部、その直上に半幅のSubtitleを中央揃え、Configが左上、Hintが右寄せで利用可能な高さ全体です。狭い画面では字幕の可読幅を確保し、補助パネルを折りたたみます。新しい保存scopeで以前の配置が上書きしないようにしています。

WebはEJDict-hand（CC0 1.0、46,916件）を初回に既存IndexedDBへ読み込みます。既に英語辞書があれば混在させず、その辞書を使います。原本の固定コミット・ハッシュ・CC0・加工内容は `public/dictionaries/LICENSE.txt` に記録します。Chrome拡張版の辞書は従来どおり利用者が選んだTSVを使います。

`pnpm build` の `.output/chrome-mv3` をChromeで読み込みます。既に開いている動画の拡張ポップアップで開始・終了秒を指定すると、その区間を通常のOverlayで開けます。本編字幕とクリップの進捗は分離します。Netflixは既存のトラック選択・Auto fetch・シーク処理を再利用します。新しい権限は追加していません。新しいタブへの無許可の自動注入は行いません。

ポップアップのおすすめボタンは独立したWebデモを開きます。MV3ページで外部YouTube APIスクリプトは実行しません。Webデモの利用に拡張機能は必要ありません。

## コンテンツ方針と今回の例外

原則は動画・字幕URLと区間・言語情報のみを管理し、利用者側で取得します。今回はユーザーが認めた例外として、配布・加工可能なライセンスを確認したBlender Foundationの英語字幕2件と同じ作品の公式日本語字幕2件を同梱します。動画本体・音声・サムネイルは同梱していません。開発用に制作したオリジナル動画も配布していません。

カタログは `src/data/recommendedVideos.ts`、字幕の原本・帰属・出典・ライセンス・ハッシュは `public/captions/LICENSE.txt` です。

- Sintel: 公式YouTube `eRsGyueVLvQ`、英語字幕、107–156秒。CC BY 3.0。公式方針: https://durian.blender.org/sharing/
- Tears of Steel: 公式YouTube `R6MlUcmOul8`、英語字幕、218–249秒。CC BY 3.0。公式方針: https://mango.blender.org/sharing/

字幕は公式原本のまま保存しています。実際のYouTube CCと各3地点で時刻を照合し、この2つのアップロードではオフセット0を確認しています。別のアップロードや改訂版は再検証が必要です。UIから帰属・ライセンス・出典を確認できます。

おすすめでは公式日本語字幕を初期表示し、Subtitle内で「日本語 / 英語（答え）」を切り替えます。字幕の翻訳は独立した時刻で合わせ、配列の番号では対応付けません。×で閉じた後はConfigから再表示できます。日本語データのない字幕では日本語を選択不可にし、原文を表示します。

利用者自身のYouTube URLと字幕ファイルも読み込めます。字幕ファイルや学習状態を開発側サーバーへ送信しません。

## 共通制御と検証範囲

`PlaybackAdapter` と `registerPlaybackTarget` が実プレーヤーの時刻・状態・シーク・速度・イベントを通常Overlayへ接続します。隠れたvideo要素や独自の仮想時計で同期しません。通常のHTML5動画も従来どおり使用できます。Webの保存はそのoriginのlocalStorage、拡張は既存chrome.storage、辞書はそれぞれのIndexedDBです。

`ClipSession` は未完了問題のループを既存Overlayに任せ、入力完了後に区間末を監視します。外部シークと内部ループを区別し、動画切替時はタイピング・ヒント・リスナー・タイマーを破棄します。YouTubeの再生開始は実際のPLAYING通知で確認し、自動再生制限は公式プレーヤーの操作に誘導します。公式操作UIを隠しません。

YouTube iframe内のCC DOMは別originであり親ページから読めません。公式IFrame APIも字幕本文を返しません。このWebデモはCC抽出に依存せず、上記の許諾済み字幕を使用します。参照: https://developers.google.com/youtube/iframe_api_reference

通常E2Eは実字幕と通常UIを使い、プレーヤーAPIのみを制御可能な代替へ置換します。実サービスのストリーミングは `test:youtube` で別途確認します。Netflixのログイン済みアカウント、物理スピーカーの聴感、利用者固有の既存動画・辞書データは未検証です。公開前に通常Chromeで字幕・辞書・復習・区間シークを普段のデータでも確認してください。

GitHub Pagesは `gh-pages` ブランチのビルド成果物を配信します。ソースのPRは自動マージしません。拡張のRelease公開はmasterのpushだけです。

## Webデモ内の案内

ページ最後のセクションで、WebはChrome拡張機能の一部を体験するデモとして案内します。拡張版のYouTube / Netflix / Prime Video等、Bilibili等の中国語タイピング、ローカル動画・字幕・音声によるオフライン利用、対応作品の誤答時日本語音声への切替を紹介しています。実サービスのログインを要する動作は上記の検証範囲に従います。

「好きなYouTube動画で遊ぶ」には、公式yt-dlp READMEに基づく字幕のみ取得コマンドを載せています。`--skip-download --no-playlist --write-subs --sub-langs "en.*" --sub-format vtt`、自動字幕は `--write-auto-subs` を使います。保存したVTTを利用者が読み込みます。この説明の実ダウンロードは未検証で、デモ自体はyt-dlpを実行しません。
