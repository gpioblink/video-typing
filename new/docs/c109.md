# C109 即プレイとWebデモ

## 起動・検証

開発対象は `new/` のWXT / React 18 / TypeScript製Chrome MV3拡張です。リポジトリ直下のReact 16 / Storybookは初期プロトタイプとして残しています。Node.js 24、pnpm 10.12.4を使います。

```sh
cd new
pnpm install --frozen-lockfile
pnpm dev:web
```

表示されたHTTP URLを新しいChromeプロファイルで開き、おすすめを選びます。初回は「入力 → 聞き直し → 完走」の操作を体験します。自動再生がブロックされた場合は「再生する」を押してください。完走後は再挑戦または自由練習へ進めます。完走は動画区間の終了を指し、入力できた文字数を別途表示します。

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm build:web
pnpm exec playwright install chromium
pnpm test:e2e
# 任意: 外部サービスの実再生検証（ネットワークが必要）
pnpm test:youtube
```

`pnpm build` の成果物 `.output/chrome-mv3` をChromeの「パッケージ化されていない拡張機能を読み込む」で読み込み、ポップアップの「おすすめをすぐプレイ · 40秒」を選びます。`pnpm build:web` は `dist/web` を生成します。`pnpm preview:web` でHTTP配信して確認できます。YouTube APIにはHTTP(S)ページが必要なため、HTMLファイルを直接開かないでください。

E2Eは両ビルド後に実行します。実メディアでの初回チュートリアル・同一クリップ3回連続完走、拡張ポップアップからの起動、停止・再開・シーク、クリップ切替、読込失敗と再試行、YouTube API代替によるUI検証を対象にしています。API代替テストは実YouTubeのストリーミング成功を証明するものではありません。最終実行結果はPRに記載します。

## クリップとサンプルの権利

共通カタログは `src/lib/clips.ts` です。`PracticeClip` は `id`、タイトル・説明、言語、動画ソース、開始・終了秒、時刻付き練習文、同期オフセット・表示設定を持ちます。`validateClip` で30〜90秒の区間、非重複cue、文字数・言語・同期設定、動画ID / ソースを検証します。YouTube URLはHTTPSの対応ホストから動画IDだけを取り出します。練習文はReactのテキストとして表示します。

おすすめ2本は各40秒、4問のオリジナル幾何アニメーションと合成英語音声です。配布物は `public/demo/`、由来とCC0の記載は同ディレクトリの `LICENSE.txt` にあります。既存作品の映像・歌詞・字幕や第三者の有償辞書データは同梱していません。YouTubeの自由練習文もオリジナルで、選んだ動画の字幕・書き起こしではありません。

再生成にはPython 3、FFmpeg（VP9 / Opus）、eSpeak NGまたはeSpeakが必要です。リポジトリ直下から実行します。

```sh
python3 new/scripts/generate-demo-media.py
```

文や区間を変更する場合はカタログと生成スクリプトを合わせて更新してください。音声は各10秒cueの開始から0.5秒後に始まります。

## Webデモの判断とYouTube制約

**WebデモはGoです。** 拡張不要の画面を実装し、オリジナル動画について新規ブラウザプロファイルでの完走を自動検証しています。公開環境へのデプロイは行っていません。

YouTube方式は公式APIの仕様上成立し、アダプターと既存タイピングUIへの接続を実装しました。ただし、実YouTubeの埋め込み・ストリーミングは回線、動画、ブラウザ、Referer、自動再生制限の影響を受けます。実Chromiumで公式サンプルのストリーム再生、実時刻、停止・再開、外部シーク後の問題同期、聞き直し、シーク後の40秒区間終了を確認しました。再現用の `pnpm test:youtube` は外部サービスに依存するため通常CIから分離しています。自動再生制限がある場合は公式プレーヤー中央の再生操作で開始できます。

- 公式APIを使い、プレーヤーの操作UIを表示します。入力UIはプレーヤーの外に置きます。YouTube動画・字幕の取得や再配信はしません。
- `seekTo` 後はAPIの `endSeconds` が効かなくなるため、`ClipSession` が実時刻で区間終了を監視します。
- 埋め込み不可・削除・非公開・識別不足などのAPIエラー、API / プレーヤー準備のタイムアウト、自動再生ブロックを通知し、再試行や別クリップへ誘導します。
- MV3拡張ページでは外部APIスクリプトを実行せず、同梱HTML5動画を使います。YouTubeアダプターはHTTP(S)のWeb版だけで使います。拡張の権限は従来の `activeTab`、`scripting`、`storage` のままで、ホスト権限は追加していません。

参照: [YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference)、[Player parameters](https://developers.google.com/youtube/player_parameters)、[Required Minimum Functionality](https://developers.google.com/youtube/terms/required-minimum-functionality)、[Chrome拡張のCSP](https://developer.chrome.com/docs/extensions/reference/manifest/content-security-policy)。

## Netflixと残る実機確認

Netflixのログイン済みページ上で使う既存のAuto fetch・字幕 / 音声トラック選択・シーク連携を維持しています。特定作品のおすすめワンクリック起動は見送りました。検証用アカウントがなく、作品・地域・言語・字幕トラックによる区間差を検証できないためです。作品の字幕同梱やDRM回避は行っていません。

公開前の最小確認手順:

1. 通常のChromeでWeb版のおすすめを1本完走し、合成音声が聞こえること、聞き直し位置、入力・再挑戦を確認します。自動テストは物理スピーカーからの聴感を確認しません。
2. 拡張を読み込み、ポップアップからおすすめを完走します。既存の手元の動画・字幕取込・辞書・復習も普段のデータで確認します。
3. Web版でYouTubeサンプルまたは埋め込み可能な動画を開き、公式UI・停止・再開・シーク・40秒終端を確認します。埋め込み禁止動画ではエラーから戻れることを確認します。
4. Netflixにログイン済みの場合だけ、既存のAuto fetchで実際の字幕・音声トラックを選び、シークと通常練習を確認します。Netflix実サービス上の動作は未検証です。

CIはブランチpushでlint・型チェック・Nodeテストと拡張ビルドを実行します。GitHub Release公開は `master` のpushだけに制限しています。この変更は運用環境へのデプロイやPRの自動マージを行いません。
