# 保存済みクリップ

拡張のPopupで現在の動画と開始・終了秒を選び、「この区間を保存」を押すと、後で同じ区間を選び直せます。タイトル・HTTPS URL・区間・言語と管理用のID・作成日時だけを、その拡張の `chrome.storage.local` に保存します。動画や字幕本体を保存する機能ではありません。

- 区間は最大90秒、保存は最大20件です。上限では既存項目を消さず、新しい保存を拒否します。同じ動画・区間・言語を保存するとタイトルを更新します。
- YouTubeは動画ID、Netflixは数値の `/watch/動画ID` で照合し、追跡用のクエリーは保存しません。その他のHTTPS動画ページはURL全体で照合します。
- 現在の動画が一致する場合は「このタブで練習する」から、既存の通常Overlay・字幕取込・区間起動を使います。Netflixは既存の字幕トラック取得・シーク連携を使い、言語や音声トラックは通常の設定で選択します。
- 別の動画は「動画ページを開く」で移動します。そのタブで拡張をもう一度クリックし、保存済みクリップを選び直してください。既存の `activeTab` 権限は新しいタブへ引き継がれないため、自動注入はしません。追加権限はありません。
- 「削除」は保存したクリップのメタデータだけを削除します。本編の字幕や学習進捗は変更しません。

## 検証

`new/` で実行します。

```sh
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm build
node scripts/check-saved-clips-popup.mjs
```

最後のコマンドはPlaywright用Chromiumが必要です。インストール済みのChromiumを使う場合は `CHROMIUM_PATH` を指定できます。実際の拡張Popupと `chrome.storage.local` で保存・再読込・削除を確認します。現在タブの情報と拡張への起動要求・新タブ作成はモックし、保存された区間とURLの受け渡しを検証します。Netflixの実アカウント、地域ごとの作品・字幕トラック、実動画再生の検証ではありません。

最低限の実機確認は、ログイン済みNetflixの再生中ページで字幕を設定し、区間を保存してPopupを開き直し、「このタブで練習する」から通常画面の同じ区間を開始することです。別の作品ページから保存済み項目を選ぶ場合は、ページ移動後に拡張を再クリックする案内も確認してください。
