# 通常の学習UIとクリップ起動

開発対象は `new/` のWXT / React / TypeScript製MV3拡張です。直下のReact 16 / Storybookは初期プロトタイプとして維持しています。

## 起動と検証

Node 24、pnpm 10.12.4を使用します。

```sh
cd new
pnpm install --frozen-lockfile
pnpm dev:web
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm build:web
pnpm exec playwright install chromium
pnpm test:e2e
# 外部サービスの実再生検証（通常CIとは分離）
pnpm test:youtube
```

Webデモ: https://gpioblink.com/video-typing/

動画を選択し、開始・終了秒または字幕の境界を選んで「開く」を押します。開いた画面は拡張と同じ `OverlayApp` / `DraggablePanel` / `TypingPart/Window` / `Hint` / `ConfigPanel` / `SubtitlePanel` です。別のタイピングゲームは実装していません。未完了の問題は通常版と同じようにループし、選択区間の入力を完了すると再挑戦できます。

初回は入力・聞き直し・完走を案内します。選択画面のチェックで無効化でき、再生中はスキップと「操作案内」からの再表示ができます。辞書は既存と同じTSVをブラウザ内IndexedDBへ取り込みます。

`pnpm build` の `.output/chrome-mv3` をChromeで読み込みます。既に開いている動画の拡張ポップアップで開始・終了秒を指定すると、その区間を通常のOverlayで開けます。本編字幕とクリップの進捗は分離します。Netflixは既存のトラック選択・Auto fetch・シーク処理を再利用します。新しい権限は追加していません。新しいタブへの無許可の自動注入は行いません。

ポップアップのおすすめボタンは独立したWebデモを開きます。MV3ページで外部YouTube APIスクリプトは実行しません。Webデモの利用に拡張機能は必要ありません。

## コンテンツ方針と今回の例外

原則は動画・字幕URLと区間・言語情報のみを管理し、利用者側で取得します。今回はユーザーが認めた例外として、配布・加工可能なライセンスを確認したBlender Foundationの英語字幕2件のみを同梱します。動画本体・音声・サムネイルは同梱していません。開発用に制作したオリジナル動画も配布していません。

カタログは `src/data/recommendedVideos.ts`、字幕の原本・帰属・出典・ライセンス・ハッシュは `public/captions/LICENSE.txt` です。

- Sintel: 公式YouTube `eRsGyueVLvQ`、英語字幕、107–156秒。CC BY 3.0。公式方針: https://durian.blender.org/sharing/
- Tears of Steel: 公式YouTube `R6MlUcmOul8`、英語字幕、218–249秒。CC BY 3.0。公式方針: https://mango.blender.org/sharing/

字幕は公式原本のまま保存しています。実際のYouTube CCと各3地点で時刻を照合し、この2つのアップロードではオフセット0を確認しています。別のアップロードや改訂版は再検証が必要です。UIから帰属・ライセンス・出典を確認できます。

利用者自身のYouTube URLと字幕ファイルも読み込めます。字幕ファイルや学習状態を開発側サーバーへ送信しません。

## 共通制御と検証範囲

`PlaybackAdapter` と `registerPlaybackTarget` が実プレーヤーの時刻・状態・シーク・速度・イベントを通常Overlayへ接続します。隠れたvideo要素や独自の仮想時計で同期しません。通常のHTML5動画も従来どおり使用できます。Webの保存はそのoriginのlocalStorage、拡張は既存chrome.storage、辞書はそれぞれのIndexedDBです。

`ClipSession` は未完了問題のループを既存Overlayに任せ、入力完了後に区間末を監視します。外部シークと内部ループを区別し、動画切替時はタイピング・ヒント・リスナー・タイマーを破棄します。YouTubeの再生開始は実際のPLAYING通知で確認し、自動再生制限は公式プレーヤーの操作に誘導します。公式操作UIを隠しません。

YouTube iframe内のCC DOMは別originであり親ページから読めません。公式IFrame APIも字幕本文を返しません。このWebデモはCC抽出に依存せず、上記の許諾済み字幕を使用します。参照: https://developers.google.com/youtube/iframe_api_reference

通常E2Eは実字幕と通常UIを使い、プレーヤーAPIのみを制御可能な代替へ置換します。実サービスのストリーミングは `test:youtube` で別途確認します。Netflixのログイン済みアカウント、物理スピーカーの聴感、利用者固有の既存動画・辞書データは未検証です。公開前に通常Chromeで字幕・辞書・復習・区間シークを普段のデータでも確認してください。

GitHub Pagesは `gh-pages` ブランチのビルド成果物を配信します。ソースのPRは自動マージしません。拡張のRelease公開はmasterのpushだけです。
